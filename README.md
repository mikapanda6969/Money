# 株主優待かんたん検索

「自分の予算」と「欲しい優待の種類」から、株主優待制度のある企業を探せる日本語Webアプリです。株を初めて知る方にも使いやすいよう、大きな文字とシンプルな2ステップ操作で構成しています。

## 主な機能

- 1株あたりのおおよその価格帯と、優待の種類による絞り込み
- 株価、最低株数、概算必要金額、優待内容、権利確定月、保有期間条件のカード表示
- 企業公式サイトへの確認リンク
- `localStorage`を利用した「気になる優待」の端末内保存
- スマートフォンを優先したレスポンシブデザイン

表示データはアプリ内の固定サンプルです。リアルタイムの株価情報ではありません。利用時は、各企業の公式サイトや証券会社で最新情報を確認してください。

## ローカルで確認する

外部サーバーやビルド作業は不要です。`index.html`をブラウザで直接開くか、簡易HTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## GitHub Pagesで公開する

1. GitHub上のリポジトリで **Settings** を開きます。
2. 左側の **Pages** を開きます。
3. **Build and deployment** のSourceに **Deploy from a branch** を選択します。
4. 公開するブランチと `/ (root)` を選び、**Save** を押します。
5. 表示された公開URLへアクセスします。

`index.html`、`styles.css`、`script.js`だけで動作するため、そのままGitHub Pagesへ公開できます。
